# Define Offline Operations and Synchronization Rules

Type: grilling
Status: open
Blocked by: 01, 02, 03
Labels: `wayfinder:grilling`

## Question

Which warehouse actions must remain available without a network connection, and how should queued changes synchronize when connectivity returns? Decide how the system handles concurrent offline edits by multiple staff, especially conflicting receipts, counts, transfers, or picks against the same stock.
