# 10: Count Stock and Resolve Discrepancies

**What to build:** Operators record physical counts, supervisors review discrepancies, and approved corrections update stock with attributable movement history.

**Blocked by:** 09: Receive Stock and Find It by Location; 04: Define Stock Availability, Holds, and Reservations; 06: Define Staff Roles, Permissions, and Audit Controls.

**Status:** ready-for-agent

- [ ] An authorized operator can count stock for an item at an allowed location using the agreed units and identity rules.
- [ ] The application shows the difference between the physical count and the recorded quantity for review.
- [ ] An authorized user can approve or otherwise resolve a discrepancy according to the agreed controls, and the resulting adjustment is traceable.
- [ ] The end-to-end acceptance test verifies the count, discrepancy outcome, and persisted movement history through the user-facing application.
