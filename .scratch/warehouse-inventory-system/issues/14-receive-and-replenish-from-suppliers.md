# 14: Receive and Replenish Stock from Suppliers

**What to build:** Planners see agreed replenishment suggestions, create the purchasing record included in scope, and receive resulting supply into inventory.

**Blocked by:** 07: Define Replenishment and Purchasing Decisions; 04: Define Stock Availability, Holds, and Reservations; 09: Receive Stock and Find It by Location.

**Status:** ready-for-agent

- [ ] An authorized planner can identify items needing replenishment using the agreed stock, demand, and incoming-supply signals.
- [ ] The planner can create or manage the purchasing record included in the agreed MVP.
- [ ] Received supplier quantities update the appropriate inventory locations and retain the agreed traceability to the replenishment record.
- [ ] The end-to-end acceptance test verifies a replenishment-to-receipt workflow and persisted stock outcome through the user-facing application.
