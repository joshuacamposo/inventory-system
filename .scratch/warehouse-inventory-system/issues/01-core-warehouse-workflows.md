# Define Core Warehouse Workflows and MVP Scope

Type: grilling
Status: open
Labels: `wayfinder:grilling`

## Question

Which warehouse operations must the first version support, and what is the intended end-to-end flow for each? Decide the required boundaries for receiving and putaway, stock counts and corrections, picking/packing/dispatch, returns, and inter-location transfers; distinguish essential first-release flows from later scope.
