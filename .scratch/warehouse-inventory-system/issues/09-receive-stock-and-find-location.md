# 09: Receive Stock and Find It by Location

**What to build:** Staff can manage the agreed item identity and warehouse locations, receive stock into a location or bin, and find current quantities and movement history in the application.

**Blocked by:** 01: Define Core Warehouse Workflows and MVP Scope; 02: Define Item Identity, Barcodes, and Stocking Units; 03: Define the Warehouse and Bin Location Model; 06: Define Staff Roles, Permissions, and Audit Controls.

**Status:** ready-for-agent

- [ ] An authorized staff member can create or select an item using the agreed identifiers and stocking units.
- [ ] An authorized staff member can receive a quantity into an allowed warehouse location and see the resulting on-hand stock.
- [ ] A user can locate stock by item and location and inspect its recorded movement history.
- [ ] The end-to-end acceptance test verifies the receiving workflow and persisted inventory outcome through the user-facing application.
